# Excel Searcher

Excel Searcher는 C++로 제작된 데스크탑 애플리케이션으로, 
여러 개의 Excel 파일(.xlsx)을 한 번에 불러와서 원하는 키워드를 쉽고 빠르게 검색할 수 있습니다.  

검색 결과는 파일명, 시트명, 셀 위치와 함께 표시되며, 
간단한 GUI를 통해 사용자가 직관적으로 엑셀파일을 검색할 수 있도록 설계되었습니다.

---

## 주요 기능

- **여러 Excel 파일(.xlsx) 동시 로드**
- **키워드 전체 검색 (모든 시트, 모든 셀)**
- **검색 결과 테이블 뷰**
- **Unicode/Korean 텍스트 완전 지원**
- **직관적인 ImGui 기반 사용자 인터페이스**

---

## 사용 기술

- **C++17**
- [Dear ImGui](https://github.com/ocornut/imgui)  
- [ImGuiFileDialog](https://github.com/aiekick/ImGuiFileDialog)  
- [OpenXLSX](https://github.com/troldal/OpenXLSX)
